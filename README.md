# Prompt Gnome 🧙‍♂️ — AI Prompt Engineering Assistant

Репозиторій містить системні інструкції та операційну методологію (плейбук) для налаштування спеціалізованого асистента **Google Gem — Prompt Gnome**.

Prompt Gnome призначений для перетворення ідей, референсів та брифів у точні, естетичні та дієві промпти для зовнішніх генераторів зображень і відео (Midjourney, Nano Banana / Gemini, Kling, Seedance, GPT Images, Krea тощо).

---

## 📁 Структура репозиторію

- **[`Botinstructions.md`](./Botinstructions.md)** — **Основні системні інструкції (System Prompt)**. Задає роль, правила спілкування, структурований онбординг, режими роботи (Prompt, Concept, Reference, Edit, Video, Troubleshooting), специфіку окремих моделей та обов'язковий формат виводу промптів у блоках коду для копіювання в 1 клік.
- **[`Playbookprompsforbot.md`](./Playbookprompsforbot.md)** — **Операційна методологія та база знань (Knowledge Base)**. Розкриває концептуальний рушій (Concept Engine), асоціативні ланцюжки, креативні операції, чекліст аналізу референсів (об'єктиви, світло, контраст), таймінг і фізику відео, а також детальну матрицю діагностики невдалих генерацій.

## 🚀 Як налаштувати Google Gem

1. Відкрийте [Gemini Gems](https://gemini.google.com/gems) і натисніть **New Gem** (або створіть нового бота).
2. Заповніть базові налаштування:
   - **Name**: `Prompt Gnome 🧙‍♂️`
   - **Description**: `Експерт зі створення точних промптів для генерації зображень і відео в Midjourney, Nano Banana, Kling, Seedance, GPT Images та інших ШІ.`
3. **Instructions**: скопіюйте та вставте повний вміст файлу [`Botinstructions.md`](./Botinstructions.md).
4. **Knowledge Files**: додайте файл [`Playbookprompsforbot.md`](./Playbookprompsforbot.md) через скріпку / кнопку додавання файлів знань.
5. **Conversation Starters (Швидкі кнопки діалогу)**:
   - 🎨 `Створити промпт для зображення`
   - 🎬 `Написати промпт для відео (Kling, Seedance)`
   - 💡 `Придумати креативну концепцію`
   - 🛠️ `Відредагувати картинку або покращити промпт`
6. Натисніть **Save** (Зберегти).

## 🌟 Ключові принципи Prompt Gnome

- **Економічність слів замість декору**: відмова від порожніх прикметників на кшталт "stunning, cinematic, masterpiece" на користь точних фізичних і оптичних описів.
- **Preservation-first**: при редагуванні зберігається все, що користувач не просив змінити.
- **Причинність у відео (Causal motion)**: опис руху пояснює його причину й динаміку камери, а не є випадковим набором анімацій.
- **Зручність**: готові промпти виводяться у віконцях коду для швидкого копіювання в один клік.
